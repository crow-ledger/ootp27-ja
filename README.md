# Out of the Park Baseball 27 日本語化（非公式・暫定版）

Steam版 **Out of the Park Baseball 27**（Windows）を日本語で遊べるようにする、有志による非公式の日本語化です。

- 無料です
- OOTP Developments、MLB、MLBPA とは関係ありません
- ゲーム本体のファイルや英語の原文は含まれていません。あなたのPCにあるゲームのファイルをもとに、日本語のファイルをその場で組み立てて入れます
- 権利者の方から取り下げの求めがあった場合は、すぐに公開をやめます

## ダウンロード

**[最新版はこちら（Releases）](../../releases/latest)** から `OOTP27日本語化.exe` をダウンロードしてください。

## 日本語になるところ

- メニュー・ボタン・設定などの画面の文字
- 試合の実況、ニュース、メール
- 選手名（カタカナ。日本人選手は漢字）、あだ名
- 球団名、都市名、国籍、出身地、学校名
- けがの名前、ヒント、歴史解説

## 入れ方

1. Steam のライブラリで OOTP27 を右クリック →「プロパティ」→「一般」の「起動オプション」に `enable_all_languages` と入力する
2. ゲームを終了した状態で `OOTP27日本語化.exe` をダブルクリックする
   - 「Windows によって PC が保護されました」と出たら、「詳細情報」→「実行」を押してください（個人が作ったプログラムに出る表示です）
3. 黒い画面に番号の一覧が出るので、`1` と入力して Enter を押す（数分かかります）
4. ゲームを起動し、Settings → Change Language で **JAPANESE** を選ぶ

Python など、ほかに入れるものはありません。

## 元に戻すには

exe を起動して `2` を選びます。Steam の「ファイルの整合性を確認」でも戻せます。

## 新しい版が出たら／ゲームが更新されたら

新しい exe をダウンロードして、もう一度 `1` を選んでください。

## 知っておいてほしいこと

- 選手名・あだ名・国籍・学校名は、日本語化したあとに**新しく作ったゲーム**から日本語になります
- **歴史ゲーム**（実在の過去の年で始めるゲーム）を新しく作るときは、作る前に exe の `3`、作り終えたら `4` を実行してください。`3` をしないで作ると、選手の出身地が「不明」になります。今年のMLBや架空リーグでは不要です
- 架空リーグを自分で作る画面の「ニックネームをランダム化する」は効きません。愛称は手で入力してください

## 分かっている不具合・直せていないところ

- ゲームの起動直後に、まれに落ちることがあります。もう一度起動すれば動きます
- 成績表の「所属」の列で、マイナー球団の名前が途中で切れて出ます
- 順位の「1st」「2nd」、日付の一部の記号などは英語のままです
- 訳の多くは機械的に作って見直したものです。不自然な言い回しが残っています

暫定版です。少しずつ直していきます。
